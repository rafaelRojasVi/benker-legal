Política de privacidad

Última actualización: 26 de octubre de 2026

Quién usa la aplicación

La aplicación es una herramienta interna de BENKER. Solo la usan cuentas de correo de la propia empresa, autorizadas por sus responsables.

Qué datos se usan

Con permiso de lectura de Gmail, la aplicación lee los correos enviados desde los buzones de BENKER y sus adjuntos (por ejemplo, PDF de cotizaciones), para registrar en el sistema comercial interno qué cotización se envió, a quién y cuándo. Con permiso de envío, envía correos desde esos mismos buzones cuando una persona de BENKER lo decide.

Dónde quedan los datos

Los datos se guardan en los sistemas internos de BENKER. No se venden, no se comparten con terceros y no se usan para publicidad ni para entrenar modelos de inteligencia artificial.

Uso limitado de los datos de Google

El uso que hace la aplicación de la información recibida de las API de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Cómo retirar el acceso

El titular de la cuenta puede retirar el acceso en cualquier momento desde myaccount.google.com/connections. Al retirarlo, la aplicación deja de leer y de enviar correo.
